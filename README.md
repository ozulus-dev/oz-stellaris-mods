# oz-stellaris-mods

Repository for my Stellaris mods. Each mod lives in its own folder with a
`descriptor.mod`. See [CHANGELOG.md](CHANGELOG.md) for a dated history of
changes.

## Contents

| Mod | Folder | README | Description | Stellaris version |
| --- | --- | --- | --- | --- |
| Fortress Designation for Ecumenopolis | `fortress_ecu_designation/` | [README](fortress_ecu_designation/README.md) | Adds a Fortress colony designation for Ecumenopolis worlds, built around defense and soldier training. | 4.5.* |
| Haruspex | `haruspex/` | [README](haruspex/README.md) | Adds the Cybernetic Creed's Haruspex and Technophant jobs to Spiritualist empires through the Haruspex Creed civic, plus a civic building and council position. | 4.5.* |
| Megastructure System Limit Removal | `remove_mega_limits/` | [README](remove_mega_limits/README.md) | Removes the per-system "no existing megastructure" restriction for the Mega Shipyard, Sentry Array, Strategic Coordination Center, Science Nexus, and Interstellar Assembly. | 4.5.* |

Versions reflect the `supported_version` declared in each mod's `descriptor.mod`.
