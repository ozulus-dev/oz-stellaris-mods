# oz-stellaris-mods

Repository for my Stellaris mods. Each mod lives in its own folder with a
`descriptor.mod`. See [CHANGELOG.md](CHANGELOG.md) for a dated history of
changes.

## Contents

| Mod | Folder | README | Description | Stellaris version |
| --- | --- | --- | --- | --- |
| Ad Astra + Planetary Diversity - More Arcologies Patch | `adastra_pd_arcologies_patch/` | [README](adastra_pd_arcologies_patch/README.md) | Merges the Ad Astra and Planetary Diversity - More Arcologies versions of `district_city`, keeping Ad Astra's age-based upkeep and PD's additional arcology district conversions. | 4.5.* |
| Combined Civics | `combined_civics/` | [README](combined_civics/README.md) | Adds two permanent civics: Techno-Aristocratic Guilds (Technocracy + Merchant Guilds + Aristocratic Elite) and Philosopher Admiralty (Diplomatic Corps + Distinguished Admiralty + Philosopher King). | 4.5.* |
| Combined Civics - Ad Astra Compatibility | `combined_civics_adastra_compat/` | [README](combined_civics_adastra_compat/README.md) | Merges Combined Civics' civic checks with Ad Astra and the Irony patch mod for Noble Estates, Research Institute, Galactic Stock Exchange, Noble Chateaus and Archaeostudies Expertise traits. | 4.5.* |
| Fortress Designation for Ecumenopolis | `fortress_ecu_designation/` | [README](fortress_ecu_designation/README.md) | Adds a Fortress colony designation for Ecumenopolis worlds, built around defense and soldier training. | 4.6.* |
| Haruspex | `haruspex/` | [README](haruspex/README.md) | Adds the Cybernetic Creed's Haruspex and Technophant jobs to Spiritualist empires through the Haruspex Creed civic, plus a civic building and council position. | 4.6.* |
| Megastructure System Limit Removal | `remove_mega_limits/` | [README](remove_mega_limits/README.md) | Removes the per-system "no existing megastructure" restriction for the Mega Shipyard, Sentry Array, Strategic Coordination Center, Science Nexus, and Interstellar Assembly. | 4.6.* |

Versions reflect the `supported_version` declared in each mod's `descriptor.mod`.
